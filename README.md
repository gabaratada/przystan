# Ośrodek Przystań — static snapshot

This repository contains a static snapshot of the public homepage at [osrodekprzystan.com](https://osrodekprzystan.com/), captured on 5 November 2026, along with its locally downloaded theme assets and images.

GitHub Pages deploys the repository root on pushes to `main` using `.github/workflows/pages.yml`.

This is a one-page snapshot. WordPress-powered newsletter submission and other server-side features are unavailable here; the e-book link points back to the original site. Navigation links continue to the original site.
